FIELDCheck MOBILE QA NOTES
==========================

Responsive improvements applied for phones (<=560px) and small phones (<=360px):
- Full-width main content with no horizontal page overflow.
- Bottom navigation remains usable and horizontally scrollable for all navigation items.
- Safe-area padding is included for phones with a home indicator/notch.
- Topbar controls are compact and horizontally scrollable instead of overflowing.
- Camera modal becomes a full-screen mobile sheet using dynamic viewport height.
- Camera preview, guide frame, reference-card zone, status message and detection cards scale down.
- Camera detection cards remain horizontally scrollable.
- Capture/Import/Flash controls wrap and keep touch-friendly targets.
- Biometric login receives mobile-safe inset spacing.
- Pre-capture checklist uses compact cards and readable spacing.
- Tables use horizontal scrolling instead of breaking the page layout.
- Reduced-motion preference is respected.
- Export All PDF has an offline fallback if the jsPDF CDN is unavailable.

Camera safety behavior:
- A face, random colour, or unrelated object is not treated as a positive/negative test.
- The capture guard returns INCONCLUSIVE/manual review when a valid test kit is not confidently detected.
- A real field classification requires a validated test-kit capture and should be confirmed by an appropriate laboratory process.

Testing note:
- JavaScript syntax was checked with Node.js.
- ZIP archive integrity was checked after packaging.
- Headless Chromium was attempted at a 390x844 viewport; the container Chromium process did not finish within the test timeout, so no claim of pixel-perfect device rendering is made. The responsive CSS was inspected directly and targeted to common mobile viewport sizes.
